# Operation Hydra - WHOIS / Domain Analysis

## Domains Investigated

| Domain | Purpose in Simulation | Status |
|---|---|---|
| hydra-bank.example | Fake banking sender | Documentation domain |
| hydra-pay.example | Fake payment sender | Documentation domain |
| hydra-security.example | Fake security sender | Documentation domain |

## Findings

All three domains use the .example namespace.

The .example namespace is reserved for documentation and examples.
Therefore, these domains are intentionally non-operational within this
academic simulation.

No real registrant information, victim infrastructure or malicious
domain ownership is being attributed.

## Simulated WHOIS Investigation Procedure

For a real domain investigation, an investigator would collect:

- Domain registration date
- Registrar
- Nameservers
- Domain status
- Registration/expiration information
- Relevant historical DNS information
- Associated infrastructure

The collected information should be preserved as evidence and correlated
with email headers, DNS records and other indicators.

## Conclusion

The simulated sender domains are classified as spoofing indicators for
this assignment because the email identities are intentionally deceptive.
No real-world attribution is made.
